# TIME Overview

## Description
TIME คือเวลาที่เล็กกว่าระดับวัน เช่น ชั่วโมง นาที ช่วงเช้า บ่าย เย็น หรือเวลานาฬิกา Entity นี้ต่างจาก DATE เพราะไม่ได้ระบุวัน/เดือน/ปีเป็นหลัก

## เกณฑ์การจำแนก
- ใช้ TIME กับเวลาในวัน เช่น 14:30 น., ตอนเช้า, 下午两点半
- ถ้ามีวัน เดือน ปี ให้ใช้ DATE หรือแยก DATE/TIME ตาม annotation policy
- ถ้าเป็นช่วงกิจกรรมที่มีชื่อเฉพาะ ให้พิจารณา EVENT
- ถ้าเป็นระยะเวลา เช่น 3 ชั่วโมง อาจจัดเป็น QUANTITY ตามบริบท

## Case ตัวอย่าง
ประโยค: "การประชุมเริ่มเวลา 14:30 น. ที่ห้องประชุมใหญ่"

Entity: "14:30 น."  
Type: TIME  
เหตุผล: คำนี้ระบุเวลาภายในวันเป็นชั่วโมงและนาที ไม่ได้ระบุวันในปฏิทิน จึงเป็น TIME
