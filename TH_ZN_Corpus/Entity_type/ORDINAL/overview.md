# ORDINAL Overview

## Description
ORDINAL คือคำบอกลำดับ ตำแหน่ง อันดับ หรือครั้งที่ Entity นี้ต่างจาก CARDINAL เพราะไม่ได้บอกจำนวนรวม แต่บอกตำแหน่งในลำดับ

## เกณฑ์การจำแนก
- ใช้ ORDINAL กับคำอย่าง ที่หนึ่ง อันดับสอง ครั้งที่สาม 第一
- ถ้าคำเป็นจำนวนนับทั่วไปโดยไม่บอกลำดับ ให้ใช้ CARDINAL
- ถ้าลำดับเป็นส่วนหนึ่งของชื่อเหตุการณ์ เช่น สงครามโลกครั้งที่ 2 อาจบันทึก EVENT เป็นหลักและ cross-reference ORDINAL
- ถ้าตัวเลขมีหน่วยวัด ให้ใช้ QUANTITY

## Case ตัวอย่าง
ประโยค: "รายงานฉบับนี้เป็นการประเมินครั้งที่สามของโครงการ"

Entity: "ครั้งที่สาม"  
Type: ORDINAL  
เหตุผล: คำนี้บอกลำดับของการประเมิน ไม่ได้บอกจำนวนการประเมินทั้งหมด จึงเป็น ORDINAL
