# NORP Overview

## Description
NORP คือสัญชาติ กลุ่มชาติพันธุ์ กลุ่มศาสนา หรือกลุ่มการเมือง Entity นี้ใช้กับกลุ่มคนตามอัตลักษณ์ ไม่ใช่ประเทศ ภาษา หรือองค์กร

## เกณฑ์การจำแนก
- ใช้ NORP กับคำที่หมายถึงคนหรือกลุ่มคน เช่น คนไทย ชาวพุทธ
- ถ้าหมายถึงประเทศหรือพื้นที่ ให้ใช้ GPE
- ถ้าหมายถึงภาษา ให้ใช้ LANGUAGE
- ถ้าหมายถึงพรรคหรือองค์กรการเมืองที่มีโครงสร้าง ให้ใช้ ORG

## Case ตัวอย่าง
ประโยค: "คนไทยจำนวนมากเดินทางกลับบ้านในช่วงเทศกาล"

Entity: "คนไทย"  
Type: NORP  
เหตุผล: คำนี้หมายถึงกลุ่มคนตามสัญชาติ ไม่ได้หมายถึงประเทศไทยหรือภาษาไทย จึงจัดเป็น NORP
