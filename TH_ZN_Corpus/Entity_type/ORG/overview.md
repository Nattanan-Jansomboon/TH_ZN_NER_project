# ORG Overview

## Description
ORG คือชื่อเฉพาะขององค์กร หน่วยงาน สถาบัน บริษัท มหาวิทยาลัย พรรคการเมือง องค์กรระหว่างประเทศ NGO หรือหน่วยงานรัฐที่มีสถานะเป็นกลุ่ม/นิติบุคคลและสามารถเป็นผู้กระทำในประโยคได้

## เกณฑ์การจำแนก
- ใช้ ORG เมื่อ entity เป็นหน่วยงานที่ประกาศ ลงทุน ผลิต ให้บริการ หรือดำเนินนโยบายได้
- ถ้าหมายถึงอาคารหรือสถานที่ตั้งขององค์กร ให้ใช้ FAC
- ถ้าหมายถึงสินค้า แอป หรือบริการเฉพาะขององค์กร ให้ใช้ PRODUCT
- ถ้าหมายถึงบุคคลในองค์กร ให้ใช้ PERSON

Entity: "ธนาคารแห่งประเทศไทย"  
Type: ORG  
เหตุผล: คำนี้เป็นหน่วยงานรัฐที่ทำกริยา "ประกาศมาตรการ" จึงหมายถึงองค์กร ไม่ใช่อาคารของธนาคารหรือผลิตภัณฑ์
