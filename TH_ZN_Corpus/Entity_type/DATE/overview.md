# DATE Overview

## Description
DATE คือวันที่ เดือน ปี ฤดูกาล ไตรมาส หรือช่วงเวลาระดับปฏิทิน Entity นี้ใช้กับเวลาที่อ้างอิงวันหรือใหญ่กว่าวัน ไม่ใช่เวลาระดับชั่วโมง/นาที

## เกณฑ์การจำแนก
- ใช้ DATE กับวันที่เต็ม เดือน ปี ช่วงปี หรือช่วงปฏิทิน เช่น 1 มกราคม 2568
- ใช้ DATE กับปี พ.ศ. หรือ ค.ศ. เมื่อทำหน้าที่ระบุเวลา
- ถ้าเป็นเวลาภายในวัน เช่น 14:30 น. ให้ใช้ TIME
- ถ้าเป็นชื่อเหตุการณ์ที่มีปีรวมอยู่ ให้พิจารณา EVENT เป็นหลัก

## Case ตัวอย่าง
ประโยค: "ระบบเริ่มเก็บข้อมูลตั้งแต่วันที่ 1 มกราคม 2568"

Entity: "1 มกราคม 2568"  
Type: DATE  
เหตุผล: คำนี้ระบุวัน เดือน และปีในปฏิทิน จึงเป็น DATE ไม่ใช่ TIME เพราะไม่ได้ระบุชั่วโมงหรือนาที
