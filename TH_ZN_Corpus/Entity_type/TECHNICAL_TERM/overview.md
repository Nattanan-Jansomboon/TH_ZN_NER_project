# TECHNICAL_TERM Overview

## Description
TECHNICAL_TERM คือคำศัพท์เฉพาะทางที่มีความหมายในโดเมนวิชาชีพหรือวิชาการ เช่น วิศวกรรม การเงิน สุขภาพ และเทคโนโลยีสารสนเทศ Entity นี้ต่างจาก PRODUCT เพราะเป็นแนวคิด วิธีการ กระบวนการ หรือคำศัพท์ ไม่ใช่ชื่อสินค้าเฉพาะ

## Domains
| Domain | ใช้กับ |
|--------|--------|
| Engineering Domain | วิศวกรรม เครื่องจักร โครงสร้าง วัสดุ ระบบควบคุม |
| Finance Domain | การเงิน ตลาดทุน ธนาคาร เศรษฐศาสตร์ บัญชี |
| Healthcare Domain | สุขภาพ การแพทย์ ยา โรค การวินิจฉัย |
| IT Domain | คอมพิวเตอร์ AI ซอฟต์แวร์ เครือข่าย ข้อมูล |

## เกณฑ์การจำแนก
- ใช้ TECHNICAL_TERM เมื่อคำเป็นศัพท์เฉพาะที่ไม่ใช่ชื่อองค์กร ผลิตภัณฑ์ หรือกฎหมาย
- ต้องระบุ domain เสมอ
- ถ้าคำเป็นชื่อซอฟต์แวร์หรือแพลตฟอร์มเฉพาะ ให้ใช้ PRODUCT
- ถ้าคำเป็นชื่อมาตรฐาน/กฎระเบียบอย่างเป็นทางการ อาจพิจารณา LAW ตามบริบท
