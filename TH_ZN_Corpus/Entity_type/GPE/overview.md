# GPE Overview

## Description
GPE คือหน่วยภูมิรัฐศาสตร์หรือพื้นที่ปกครอง เช่น ประเทศ เมือง จังหวัด เขต อำเภอ หรือรัฐ Entity นี้ใช้เมื่อสถานที่มีฐานะเป็นหน่วยการปกครอง ไม่ใช่ภูมิประเทศธรรมชาติหรืออาคาร

## เกณฑ์การจำแนก
- ใช้ GPE กับประเทศ จังหวัด เมือง เขต หรือหน่วยปกครอง
- ถ้าหมายถึงแม่น้ำ ภูเขา ทะเล หรือทะเลทราย ให้ใช้ LOC
- ถ้าหมายถึงอาคาร สนามบิน ถนน หรือสะพาน ให้ใช้ FAC
- ถ้าชื่อเมืองถูกใช้แทนรัฐบาลหรือทีม อาจยังเป็น GPE แต่ควรบันทึกบริบทไว้

## Case ตัวอย่าง
ประโยค: "กรุงเทพมหานครประกาศแผนจัดการน้ำในฤดูฝน"

Entity: "กรุงเทพมหานคร"  
Type: GPE  
เหตุผล: ในประโยคนี้หมายถึงหน่วยปกครองระดับเมือง/จังหวัดพิเศษ ไม่ใช่อาคารหรือองค์กรเอกชน จึงจัดเป็น GPE
