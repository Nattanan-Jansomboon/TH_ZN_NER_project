# LANGUAGE Overview

## Description
LANGUAGE คือชื่อเฉพาะของภาษา ภาษาถิ่น หรือระบบภาษาที่ใช้สื่อสาร Entity นี้ไม่รวมสัญชาติหรือกลุ่มชาติพันธุ์ แม้ชื่อจะคล้ายกัน

## เกณฑ์การจำแนก
- ใช้ LANGUAGE เมื่อคำหมายถึงภาษา เช่น ภาษาไทย ภาษาจีนกลาง
- ถ้าหมายถึงคนหรือสัญชาติ เช่น คนไทย 中国人 ให้ใช้ NORP
- ถ้าหมายถึงประเทศ เช่น ไทย 中国 ให้ใช้ GPE
- ถ้าหมายถึงเอกสารหรือผลงานที่เขียนด้วยภาษาใดภาษาหนึ่ง ให้ classify ตัวผลงานตาม type จริง

## Case ตัวอย่าง
ประโยค: "ระบบรองรับภาษาไทยและภาษาจีน Simplified"

Entity: "ภาษาไทย"  
Type: LANGUAGE  
เหตุผล: คำนี้หมายถึงระบบภาษา ไม่ได้หมายถึงคนไทยหรือประเทศไทย จึงเป็น LANGUAGE
