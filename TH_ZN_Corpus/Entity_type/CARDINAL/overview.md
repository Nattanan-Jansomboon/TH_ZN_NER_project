# CARDINAL Overview

## Description
CARDINAL คือจำนวนนับทั่วไปที่บอกจำนวนหรือค่าตัวเลขโดยไม่มีหน่วยวัด ไม่มีสกุลเงิน และไม่ได้ทำหน้าที่เป็นลำดับ Entity นี้ครอบคลุมทั้งตัวเลขอารบิก เลขไทย คำอ่านภาษาไทย และตัวเลขภาษาจีน

## เกณฑ์การจำแนก
- ใช้ CARDINAL เมื่อคำตอบคำถามว่า "กี่" หรือ "จำนวนเท่าไร" โดยไม่มีหน่วยเฉพาะ
- ถ้ามีหน่วยวัด เช่น กิโลกรัม เมตร คน ให้พิจารณา QUANTITY
- ถ้ามีสกุลเงิน ให้พิจารณา MONEY
- ถ้าบอกลำดับ เช่น ที่หนึ่ง ครั้งที่สาม ให้ใช้ ORDINAL

## Case ตัวอย่าง
ประโยค: "คณะทำงานแบ่งข้อมูลออกเป็นสามชุดเพื่อใช้ทดสอบโมเดล"

Entity: "สาม"  
Type: CARDINAL  
เหตุผล: "สาม" เป็นจำนวนนับของชุดข้อมูล ไม่มีหน่วยวัดเฉพาะและไม่ใช่ลำดับ จึงเป็น CARDINAL
