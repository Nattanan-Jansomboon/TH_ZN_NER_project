# EVENT Overview

## Description
EVENT คือชื่อเฉพาะของงาน เหตุการณ์ การประชุม โครงการ การแข่งขัน สงคราม หรือกิจกรรมที่เกิดขึ้นในช่วงเวลาใดเวลาหนึ่ง Entity นี้เน้น "เหตุการณ์" ไม่ใช่องค์กรผู้จัดหรือสถานที่จัด

## เกณฑ์การจำแนก
- ใช้ EVENT เมื่อชื่อมีลักษณะเป็นงานหรือเหตุการณ์ที่เกิดขึ้น
- ถ้าคำเป็นชื่อหน่วยงานผู้จัด ให้ใช้ ORG
- ถ้าคำเป็นสถานที่จัดงาน ให้ใช้ FAC, GPE หรือ LOC ตามบริบท
- ถ้าคำเป็นผลงานศิลปะ หนังสือ ภาพยนตร์ หรือเพลง ให้ใช้ WORK_OF_ART

## Case ตัวอย่าง
ประโยค: "ไทยเป็นเจ้าภาพการประชุมเอเปคและต้อนรับผู้นำจากหลายประเทศ"

Entity: "การประชุมเอเปค"  
Type: EVENT  
เหตุผล: คำนี้เป็นชื่อเหตุการณ์/การประชุมที่เกิดขึ้นในช่วงเวลาหนึ่ง ไม่ใช่ตัวองค์กรเอเปคและไม่ใช่สถานที่ จึงจัดเป็น EVENT
