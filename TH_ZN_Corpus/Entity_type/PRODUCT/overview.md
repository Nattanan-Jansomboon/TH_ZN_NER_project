# PRODUCT Overview

## Description
PRODUCT คือชื่อเฉพาะของผลิตภัณฑ์ ซอฟต์แวร์ แอป แพลตฟอร์ม รุ่นสินค้า หรือบริการเฉพาะ Entity นี้เน้นสิ่งที่องค์กรผลิตหรือให้บริการ ไม่ใช่ตัวองค์กร

## เกณฑ์การจำแนก
- ใช้ PRODUCT กับชื่อสินค้า แอป ซอฟต์แวร์ แพลตฟอร์ม หรือรุ่นผลิตภัณฑ์
- ถ้าหมายถึงบริษัทผู้ผลิต ให้ใช้ ORG
- ถ้าหมายถึง technical concept ทั่วไป ให้ใช้ TECHNICAL_TERM
- ถ้าเป็นผลงานศิลปะ หนัง เพลง หรือหนังสือ ให้ใช้ WORK_OF_ART

## Case ตัวอย่าง
ประโยค: "ผู้ใช้ทดลองสรุปเอกสารด้วย ChatGPT"

Entity: "ChatGPT"  
Type: PRODUCT  
เหตุผล: ในประโยคนี้ ChatGPT เป็นชื่อผลิตภัณฑ์/บริการซอฟต์แวร์ที่ผู้ใช้ใช้งาน ไม่ใช่ชื่อบริษัทผู้พัฒนา จึงเป็น PRODUCT
