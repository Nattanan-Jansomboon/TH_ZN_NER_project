# FAC Overview

## Description
FAC คือชื่อเฉพาะของสิ่งก่อสร้างหรือสถานที่ที่มนุษย์สร้าง เช่น อาคาร สนามบิน สะพาน ถนน เขื่อน วัด โรงพยาบาล หรือสถานี Entity นี้เน้นตัว physical facility ไม่ใช่องค์กรที่ใช้สถานที่นั้น

## เกณฑ์การจำแนก
- ใช้ FAC เมื่อคำหมายถึงโครงสร้าง อาคาร หรือสถานที่ที่มนุษย์สร้าง
- ถ้าคำหมายถึงหน่วยงานที่บริหารสถานที่ ให้ใช้ ORG
- ถ้าคำหมายถึงประเทศ เมือง จังหวัด หรือเขตปกครอง ให้ใช้ GPE
- ถ้าคำหมายถึงภูเขา แม่น้ำ ทะเล หรือพื้นที่ธรรมชาติ ให้ใช้ LOC

## Case ตัวอย่าง
ประโยค: "เที่ยวบินจากกรุงเทพฯ ลงจอดที่สนามบินสุวรรณภูมิในช่วงบ่าย"

Entity: "สนามบินสุวรรณภูมิ"  
Type: FAC  
เหตุผล: คำนี้เป็นชื่อสนามบินซึ่งเป็นสิ่งก่อสร้างและสถานที่ให้บริการการบิน ไม่ใช่เมืองหรือองค์กร จึงเป็น FAC
