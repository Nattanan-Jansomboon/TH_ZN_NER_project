# LOC Overview

## Description
LOC คือสถานที่ทางภูมิศาสตร์ที่ไม่ใช่หน่วยการปกครอง เช่น แม่น้ำ ภูเขา ทะเล อ่าว เกาะ ทะเลทราย หรือภูมิภาคธรรมชาติ Entity นี้ต่างจาก GPE เพราะไม่มีสถานะเป็นประเทศ/เมือง/จังหวัด และต่างจาก FAC เพราะไม่ได้เป็นสิ่งก่อสร้าง

## เกณฑ์การจำแนก
- ใช้ LOC กับภูมิประเทศธรรมชาติหรือพื้นที่ภูมิศาสตร์
- ถ้าเป็นประเทศ เมือง จังหวัด เขต ให้ใช้ GPE
- ถ้าเป็นอาคาร ถนน สะพาน สนามบิน ให้ใช้ FAC
- ถ้าสถานที่ธรรมชาติเป็นส่วนหนึ่งของชื่อองค์กรหรือผลงาน ให้พิจารณา type ตามบริบท

## Case ตัวอย่าง
ประโยค: "แม่น้ำเจ้าพระยาเป็นเส้นทางคมนาคมสำคัญของภาคกลาง"

Entity: "แม่น้ำเจ้าพระยา"  
Type: LOC  
เหตุผล: คำนี้เป็นชื่อแม่น้ำซึ่งเป็นภูมิประเทศธรรมชาติ ไม่ใช่หน่วยปกครองหรือสิ่งก่อสร้าง จึงเป็น LOC
